# CS50’s Introduction to Programming with Python (CS50P)

This repository contains my personal solutions to the problem sets and assignments for Harvard University's **CS50P: Introduction to Programming with Python**.

## 📁 Repository Structure

The solutions are structured by week:

- **`week0/`** — Functions, Variables (Functions, Input/Output, String Methods)
- **`week1/`** — Conditionals (If/Else, Boolean Expressions)
- **`week2/`** — Loops (For/While Loops, Iteration)
- **`week3/`** — Exceptions (Error Handling, Try/Except)
- **`week4/`** — Libraries (Modules, Packages, Command-Line Arguments)
- **`week5/`** — Unit Tests (Pytest, Testing Code)
- **`week6/`** — File I/O (Reading/Writing CSV, Images, Text Files)
- **`week7/`** — Regular Expressions (Pattern Matching, Regex)
- **`week8/`** — Object-Oriented Programming (Classes, Methods, Operator Overloading)
- **`week9/`** — Et Cetera (Generators, Map, Filter, Advanced Python Features)

## 🛠️ Tools & Technologies

- **Language:** Python 3.x
- **Testing:** `pytest`
- **IDE:** CS50 Codespace / VS Code
- **Version Control:** Git & GitHub
